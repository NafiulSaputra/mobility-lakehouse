# Benchmarks

How the numbers in this folder are produced ([ADR 0013](../adr/0013-benchmark-methodology.md)). The reports
are generated by the commands below and committed as they are.

## Local (Docker)

The month must be downloaded (`mobility-lakehouse download --month 2025-01`). Each repeat replaces the month
in every table, so the command is safe to run on existing data:

```
docker compose run --rm spark mobility-lakehouse benchmark --month 2025-01 --repeats 3
```

Report: `local_2025-01.md`. If the stream run log exists (see [streaming](../streaming.md)), the report also
shows streaming throughput.

## Databricks

Find the job ID in the job URL (`/jobs/<job ID>/runs/...`) or with `databricks jobs list --profile mobility`.
Then write the run history to a file and summarize it:

```
databricks jobs list-runs --job-id <job ID> --expand-tasks --output json --profile mobility > runs.json
uv run mobility-lakehouse databricks-timings --runs-json runs.json
del runs.json
```

Report: `databricks.md`. Only successful runs are counted.
